# Changesets

Yayımlanacak paketlerde (`@kopru/*`) değişiklik yapan her PR, bir changeset dosyası içermelidir:

```bash
pnpm changeset
```

Komut, hangi paketlerin hangi sürüm türüyle (patch / minor / major) güncelleneceğini sorar ve bu klasöre bir Markdown dosyası ekler. Sürüm notu İngilizce yazılır.

Ayrıntılar: https://github.com/changesets/changesets
